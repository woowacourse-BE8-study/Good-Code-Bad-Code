### LocalDateTime.now()

```java
public boolean isPast() {
    return LocalDateTime.of(date, time.getStartAt()).isBefore(LocalDateTime.now());
}
```
* 현재 시간은 실행할 때마다 계속 변하는 값 
* 외부 상태에 의존하면 코드 예측하기 어렵고, 테스트코드 작성이 어렵다 
  * → 시간을 내부에서 구현하지 않고 외부에서 주입받도록 변경

```java
public boolean isPast(LocalDateTime currentTime) {
    return LocalDateTime.of(date, time.getStartAt()).isBefore(currentTime);
}
```

### VO
```java
if (name == null || name.isBlank()) {
    throw new IllegalArgumentException("예약자 이름은 필수입니다.");
}
```
* 이름 데이터가 서비스의 다른 곳에서도 쓰인다면, null이나 isBlank 검증 로직을 매번 작성 
* 기본형 남용을 줄이자!
  * 이름 값객체를 생성하자

```java
public record ReservationName(String value) {
    public ReservationName {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException("예약자 이름은 필수입니다.");
        }
    }
}
```
